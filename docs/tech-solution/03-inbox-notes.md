# 03 收集箱、备注、删除与回收站

## 收集箱列表

- Tab：全部 / 网页 / 问答（本期无文档）。时间线模糊备注按时间顺序混排在「全部」中，可勾选，因为会影响整理。
- 状态筛选（下拉）：未读、已读、待整理、已入库、未采纳。两个维度独立存储：`read_status`（未读/已读）与 `organize_status`（`pending` 待整理 / `ingested` 已入库 / `rejected` 未采纳；`failed` 展示为待整理）；条目标题后同时展示两个标签。无归档概念。
- 第一版不展示判定理由、主题、片段等额外标签与描述；判定理由只存后台。
- 不提供单独的「采纳」按钮：对未采纳条目执行整理（单条 / 已选）即视为用户确认入库，跳过判定直接抽取（见 07 路径捷径）。
- 排序：固定按收集时间倒序，不提供排序下拉。
- 分页：默认 50 条/页，游标分页（`captured_at, id`）。滚动区在列表卡内，页面头部与操作栏固定。
- 单行展示：标题单行省略，悬停 tooltip 展示全文。
- 勾选：
  - 只有 checkbox 区域可勾选，行其余区域点击进入详情；checkbox 尺寸与全选一致，hover 不改变背景。
  - 全选只作用于当前筛选结果的当前页，是一次性操作；切换 Tab/筛选后保留已选 ID，不自动勾选新 Tab 内容。
  - 已选集合存在前端 store（`Set<itemId|noteId>`），跨分页保留。
- 批量操作：整理（弹窗范围默认「刚才已选的」）、删除、标为已读/未读、加标签。

## 条目详情

- 网页：Markdown 正文、原文链接、阅读记录（每次停留与总时长）、标签、收集点备注（右侧）、关联知识点。
- 问答：问题、回答、DeepSeek 思考过程（折叠）、会话链接。
- 打开详情自动置为已读（`PATCH read_status`）。
- 编辑：头部「编辑」按钮切换为「保存 / 取消」在同一位置；保存写 `item_contents.markdown`，首次编辑把原文备份到 `original_markdown`；保存后 `dirty=1`，**不触发自动整理**，页面出现待整理提示条「内容已编辑 / n 条新备注，尚未用于整理」+「重新整理」按钮。
- 返回按钮：与知识库统一样式，文案「返回」，返回当前页的上一级。

## 三类备注（整理的意图信号）

| 类型 | `scope` | 来源 | 整理时用法 | 新增/修改后 |
| --- | --- | --- | --- | --- |
| 模糊备注 | `fuzzy` | 扩展弹窗/浮窗写的、当前页未入箱时的备注；批量/全量整理时填写的要求 | 不绑定条目，整理时按语义匹配相关内容（向量相似度 + 时间邻近 ±1 天），作为关注点/关联信号 | 时间线与收集箱可删除；不触发整理 |
| 收集点备注 | `item` | 采集时对已入箱页面的备注、工作台条目详情中添加、单条整理时填写的要求；未来支持圈选/网页内备注 | 整理该条目时作为高权重意图信号 | 已整理条目新增备注只置 `dirty`，手动整理才使用 |
| 知识点备注 | `entry` | 整理时由收集点备注派生（`origin=derived`）、知识库详情中手动添加、重新整理知识点时填写的要求 | 重写该知识点正文时作为意图信号 | 不触发整理 |

- `used_at`：被某次整理消费后写入时间；未使用的备注在 UI 显示「未用于整理」标签。
- 编辑/删除备注：写 `updated_at` / `deleted_at`；编辑已用备注会清空 `used_at`。
- 详情页备注卡位于右侧，支持随时新增、编辑、删除。

## 删除与知识库同步

删除弹窗先请求 `GET /v1/workbench/items/impact?ids=` 展示影响预览，确认后单事务执行：

| 产物 | 处理 |
| --- | --- |
| 条目摘要（`organize_results`） | 删除 |
| 只来自这些条目的知识点 | 删除（软删），相关边删除 |
| 还有其他来源的知识点 | 保留，移除来源与 evidence，置 `stale=1`，下次整理用剩余来源重写 |
| `user_edited` 知识点 | 不删，移除来源；无来源时置 `orphan=1`（显示「无来源」） |
| 只有该条目作为来源的边 | 删除 |

- 选项：「同时从知识库移除」（默认勾选）；「仅删除 / 不再收集此页面 / 不再收集该网站」→ 写 `rules`，扩展下次拉取设置生效。
- 回收站：`trash.snapshot` 保存条目行、正文、备注、被删除的知识点与边、被修改知识点的修改前字段；30 天内「撤销删除」整体回滚；到期由调度器物理删除并清理孤儿 blob。
- 勾选了模糊备注时一并删除。

## 排除规则

- 类型：精确 URL、域名、URL 前缀、列表页规则（路径通配）。
- 服务端在入库时再校验一次（扩展缓存可能过期），命中则 `ignored`。
- 内置规则只读展示，随扩展版本发布。

## API

| 方法与路径 | 说明 |
| --- | --- |
| `GET /v1/workbench/items?type&status&cursor&limit=50` | 列表（含模糊备注行，`type=all` 时混排） |
| `GET /v1/workbench/items/:id` | 详情：正文、阅读记录、备注、标签、关联知识点 |
| `PATCH /v1/workbench/items/:id` | 已读状态、标签、编辑正文 |
| `POST /v1/workbench/items/bulk` | 批量已读/标签 || `GET /v1/workbench/items/impact?ids` | 删除影响预览 |
| `DELETE /v1/workbench/items`（body：ids、noteIds、removeFromKb、rule） | 移入回收站 |
| `GET/POST/PATCH/DELETE /v1/notes` | 三类备注 CRUD |
| `GET /v1/workbench/trash`、`POST .../:id/restore`、`DELETE .../:id` | 回收站 |
| `GET/POST/DELETE /v1/rules` | 排除规则 |

## 选型

本领域无需引入第三方能力：列表与选择逻辑简单，数据量（千到万级）分页即可，无需虚拟滚动库。如后续单页条数放开到数百条再引入 `@tanstack/react-virtual`。
