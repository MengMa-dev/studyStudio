# 10 设置、数据与隐私

设置为单页四个分区，左侧分区导航，单列行式布局（原型 `#/settings/:section`）。

## 采集

- 浏览器扩展：连接状态（最后上报时间、扩展端待同步数——扩展每次心跳/同步时上报）、安装扩展入口、配对令牌（掩码、复制）。
- 正文采集规则（原「学习门槛」）：入箱可见时长、滚动深度、再次停留计时下限；「正式 / 调试」预设（取代 `STUDY_STUDIO_DEV`）。
- 行为记录：开关（默认开）、无关站点黑名单（在内置类别之外追加，只记域名与时长）、行为日志保留天数（默认 14）。
- 对话平台开关：ChatGPT、DeepSeek。
- 排除规则：列表、添加、删除；内置列表页规则只读折叠展示。
- 保存后写 `settings` / `rules` 并更新 ETag，扩展最迟 5 分钟内同步（弹窗打开时立即）。

## 整理规则

- 自动整理总开关；每天定时（时间）、攒够数量（N 条）、入箱即整理三个触发器，可同时开启，总开关关闭时禁用。
- 上次 / 下次运行时间、待整理数、「整理」按钮。
- 输出语言：中文 / 跟随原文。
- 学习者档案（Learner Profile，存 `settings.learner_profile`）：设置中独立分区；另有两个入口——首页输入框右侧圆形按钮（弹窗编辑），对话中说「我是产品经理」「我最近在学 AI 相关知识」自动识别并记录：
  - 角色：自由文本，如「产品经理」；
  - 近期学习方向：多条，每条带有效期（默认 30 天），到期前提醒更新，过期不再参与整理。
  - 只作为学习判定与知识处理的加分上下文，不作为否定依据（见 07）。
- 整理记录：移出设置，作为侧栏一级页面「整理记录」（`#/runs`）：每次的时间、触发方式、活动片段数（学习 / 非学习 / 推迟）、已入库 / 未采纳 / 失败数、判定分布（新知识 / 补充 / 重复 / 不入库 / 非学习，其中规则预过滤命中数）、知识库变化、各阶段调用与 tokens；失败项可重试。设置页只保留入口链接。

## 数据与隐私

| 功能 | 实现 |
| --- | --- |
| 本地服务状态 | 地址、运行时长、SQLite 版本 |
| 数据目录 | 路径、占用（db + blobs）、条目数；「打开目录」调用系统文件管理器（`open` / `explorer` / `xdg-open`） |
| 导出备份 | `VACUUM INTO` 生成一致快照 + `blobs/` 打包为 zip（流式压缩，`archiver` 或 `fflate`）；不含 `secrets.json` |
| 导入备份 | 校验 zip 中 db 版本 → 停止调度 → 替换 → 迁移 → 重启服务内状态 |
| 重建索引 | 清空并重建 `chunks` / FTS / 向量，不修改内容；后台任务带进度 |
| 自动备份 | 每日首次启动或 03:00 `VACUUM INTO backups/`，保留 7 份 |
| 重置配对令牌 | 新令牌写文件，旧令牌立即失效；扩展显示「令牌无效」 |
| 清空所有数据 | 二次确认（输入「清空」）→ 先自动做一次备份 → 删除库内全部业务数据与 blobs |

隐私声明：收集内容、笔记、知识库均只存本机；仅整理与对话时，相关内容发送给用户配置的模型服务商。

## API

| 方法与路径 | 说明 |
| --- | --- |
| `GET/PUT /v1/settings` | 采集设置（扩展与工作台共用） |
| `GET/PUT /v1/organize/settings`、`POST /v1/organize/run`、`GET /v1/organize/runs`、`POST /v1/organize/runs/:id/retry` | 整理规则与记录 |
| `GET /v1/data/info`、`POST /v1/data/export`、`POST /v1/data/import`、`POST /v1/data/reindex`、`POST /v1/data/reveal`、`POST /v1/pairing/reset`、`POST /v1/data/wipe` | 数据管理 |

本领域无需额外选型；zip 库在 `archiver`（成熟、流式）与 `fflate`（纯 JS、更快、更小）间任选，推荐 `fflate`。
