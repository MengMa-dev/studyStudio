# 04 学习进度与时间线

## 页面结构（与原型一致）

- 左侧时间线、右侧进度纵览；日期范围（7 天 / 30 天 / 自定义）同时作用两侧。
- 页头与筛选栏固定，内容区滚动。

## 时间线

- 以时间线形式展示：每天是一个节点（日期、当天学习时长），节点下逐条展示，可折叠；不把一天做成卡片。
- 不做 20 分钟会话合并，逐条展示；每条只显示开始时间。
- 聚合规则（服务端完成）：

| 行类型 | 合并来源 | 展示 |
| --- | --- | --- |
| AI 问答 | 同一 `item` 的 `user_message_sent` + `assistant_response_completed` | 开始时间 · 平台 · 问题 |
| 网页学习 | 同一天同一 `item` 的 `webpage_captured` + `reading_session_closed` | 首次开始时间 · 标题 · 当天累计时长 |
| 模糊备注 | `notes.scope=fuzzy` | 开始时间 · 备注内容，可删除 |

- 绑定条目的备注不在时间线展示。
- 每条单行，超长省略 + tooltip；点击进入收集箱详情 / 阅读器。
- 类型筛选：网页学习、AI 问答、模糊备注（学习区上线后增加文档阅读）。

## 进度纵览

| 指标 | 口径 |
| --- | --- |
| 正在学习 | 扩展 `POST /v1/presence` 心跳（内存，60 秒无心跳即消失） |
| 学习时长 | 网页有效阅读时长（`reading_sessions.seconds`）+ 问答时长（提问到回答完成的间隔，单次上限 10 分钟） |
| 今日 | 时长、新收网页、问答、备注数；连续学习天数（当天时长 > 0 即算） |
| 近 7 天趋势 | 按天时长柱状图 |
| 来源分布 | 按站点 / 对话平台汇总时长 |
| 待处理 | 未读数、待整理数、薄弱知识点数（掌握度 < 0.3），可跳转 |

统计全部用 SQL 聚合（`GROUP BY day / site`），数据量下无需预计算表；如后续变慢再加 `daily_stats` 物化表。

## API

| 方法与路径 | 说明 |
| --- | --- |
| `GET /v1/workbench/timeline?from&to&types` | 按天分组的聚合行 |
| `GET /v1/workbench/overview?from&to` | 纵览统计 |
| `GET /v1/presence` | 正在学习（前端每 5 秒轮询或 SSE） |

## 选型（低优先级，可直接按推荐）

图表只有柱状趋势和分布条，原型已用 CSS/SVG 实现。

| 方案 | 优点 | 缺点 |
| --- | --- | --- |
| ★ 手写 SVG/CSS（沿用原型） | 零依赖，与原型像素一致 | 新增复杂图表需自写 |
| Recharts | React 声明式，够用 | 增加 ~100 KB |
| ECharts | 能力最全 | 体积大，风格需大量定制 |
